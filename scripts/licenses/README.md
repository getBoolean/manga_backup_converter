Canonical licence texts that `scripts/package_cli.dart` writes for a bundled Rust crate whose
published source carries no licence file of its own (it declares only an SPDX expression in
`Cargo.toml`). `MIT.txt` is the standard MIT text; `{{holders}}` is replaced with the crate's
declared authors. `Apache-2.0.txt` and `MPL-2.0.txt` are the unmodified texts, copied from the
`html5ever` and `cssparser` crates.
